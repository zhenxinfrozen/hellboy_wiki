# 关于本站

## 这是什么

**地狱男爵中文维基** 是基于 MediaWiki 起步、如今用纯 PHP + Markdown 文件重建的个人资料库，
收录和整理与**地狱男爵**（地狱小子、Hellboy）相关的所有中文信息。现代阅读版不依赖数据库、Docker 或 Node.js，
以「阅读体验」为核心。

这里最早完全开放编辑，如今主要作为站长本人的个人资料库使用；当然，仍欢迎有兴趣的爱好者协助完善内容。

网站内容包括：[**人物词条**](/portal/characters)、[**漫画故事索引**](/portal/stories)、[**图书系列索引**](/portal/stories)，[创作者门户](/portal/artists)下还可按[主笔画师](/browse?g=%E5%88%9B%E4%BD%9C%E8%80%85&s=%E5%86%85%E9%A1%B5%2F%E7%BA%BF%E7%A8%BF%E7%94%BB%E5%B8%88)、[封绘艺术家](/browse?g=%E5%88%9B%E4%BD%9C%E8%80%85&s=%E5%B0%81%E9%9D%A2%E7%94%BB%E5%B8%88)、[上色](/browse?g=%E5%88%9B%E4%BD%9C%E8%80%85&s=%E4%B8%8A%E8%89%B2%E5%B8%88)等职能细分浏览，
以及[**地狱男爵电影**](/browse?g=%E7%94%B5%E5%BD%B1)相关条目。

## 资料来源

网站的基础英文内容来自 Hellboy 英文维基：[FANDOM Hellboy Wiki](https://hellboy.fandom.com)。

中文条目是本人对英文条目的手工翻译，另外参考了[维基百科](https://zh.wikipedia.org)、
[地狱男爵吧](http://tieba.baidu.com/f?kw=%E5%9C%B0%E7%8B%B1%E7%94%B7%E7%88%B5&ie=utf-8)
以及各类网络文章。本站所有中文译名都基于**「不高兴汉化」**的翻译版本，在此特别鸣谢。

当然，词条的部分内容里也夹杂着我自己的碎碎念。

## 版本规划

- **18100 / 18102**：早期 MediaWiki 主站与归档站。
- **18104**：定稿稳定基线（Wiki.js 风格三栏布局）。
- **18105**：实验版 —— 自定义页面、中英文切换、英文原文同步。

## 技术说明

- 数据源：清理后的 MediaWiki 词条导出为 Markdown；信息框以 JSON 保存。
- 中英切换：顶栏 **中 / EN**，选择会被记住；英文正文缺失时自动回退中文并给出提示。
